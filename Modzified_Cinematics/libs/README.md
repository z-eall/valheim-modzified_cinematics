# ServerSync

`ServerSync.dll` is Jere/Azumatt **ServerSync** (MIT, copyright Tykea — see `LICENSE-ServerSync.txt`), compiled against this Valheim install and **ILRepacked** into `Modzified_Cinematics.dll`. Players do not install a separate ServerSync plugin.

Rebuild the DLL from [AzumattDev/ServerSync](https://github.com/AzumattDev/ServerSync) (same public contract as [JereKuusela/ServerSync](https://github.com/JereKuusela/ServerSync)) if the game’s `ISocket` surface moves again. Do not copy ServerSync `.cs` into the plugin project.
